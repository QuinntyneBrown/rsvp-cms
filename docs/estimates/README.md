## Roadmap

1. Accounts and events: reset-password, manage-account-settings, list-events, edit-event-details, manage-invite-window and delete-event.
2. Invitations: issue-personal-links, send-reminders and track-delivery-outcomes on the existing mail worker.
3. Guests, responses and page extras: export-guests, export-responses and upload-gallery-photos.
4. Dashboard and notifications (the reminder prompt, the event overview figures and the touch row actions of the dashboard summary), then the cross-cutting privacy, performance, accessibility and responsive-design work.
