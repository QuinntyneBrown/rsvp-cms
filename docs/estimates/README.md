## Roadmap

1. Accounts: sign-in, session, password reset and account settings.
2. Event setup: events (create, details, invite window, links, delete), then the event-page blocks and publishing.
3. Guest list and invitations: guests (list, manage, CSV import and export), then invitations (schedule, personal links, reminders, delivery outcomes).
4. Guest RSVP and organiser review: rsvp, responses, notifications and dashboard.
5. Cross-cutting: performance, privacy, accessibility and responsive-design, applied to each step above.
