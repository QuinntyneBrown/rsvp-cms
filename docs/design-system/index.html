How to use

The system is three files and a set of class names. Product code links the CSS, writes the documented markup and reads tokens; it never copies values out of this site.

<link rel="stylesheet" href="tokens/tokens.css">       <!-- primitives, semantic tokens, light + dark -->
<link rel="stylesheet" href="assets/components.css">  <!-- every component class -->

<button class="btn btn--primary" type="button">Send my RSVP</button>
<div class="field">
  <label class="field__label" for="code">Invitation code</label>
  <input class="input" id="code" type="text" aria-describedby="code-help">
  <span class="field__help" id="code-help">The code is on your invitation email, like MAYA-7K2Q.</span>
</div>
  • Tokens: tokens/tokens.css is the source of truth. tokens/tokens.json is the same set in W3C DTCG format for build tools; dark values sit under $extensions. tokens/contrast-pairs.json lists every colour pair the components rely on.
  • Themes: light by default, dark with data-theme="dark" on any element or automatically from the operating system unless the page sets data-theme="light". See Theming.
  • States: real pages get hover, focus and active from the browser. The data-state attribute you see in these pages forces a state for review only; never ship it.
  • React: src/shared/ui/components/ implements these pages one folder per component (see AGENTS.md). Its tokens.css is copied from here, never imported from docs/.
  • Shortcut: press t anywhere on this site to switch theme.
