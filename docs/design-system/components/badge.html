Badge

A small status pill: reply status (Attending, Declined, Waiting), event status (Draft, Invites open, Invites closed), email status, unread counts.

Overview

Dot + uppercase text, so status never relies on colour alone. Tones map to meaning, not decoration. Count badges show unread numbers and carry an aria-label with the meaning.

Anatomy

  1. Dot6px, currentColor.
  2. Label--text-overline, uppercase, wide tracking.
  3. Pill22px tall, --radius-full.

Variants

Neutral, info, success, warning, danger, solid, count.
