FileUpload

Choose or drop a CSV of guests. A real file input is the control; the drop zone is an enhancement.

WCAG 2.2 AAStatus: stableReact: FileUpload

Overview

Used by the guest import (Upload step). The button opens the native file picker (accept=".csv"); dropping a file on the zone does the same. After choosing, a file row shows the name, size and progress (ProgressBar).

Anatomy

  1. ZoneDashed --color-border-strong, --radius-lg.
  2. IconDecorative.
  3. InstructionSays both ways to add a file.
  4. ButtonPrimary; labels the hidden input.

Responsive behaviour

  • Zone is full width; on touch devices drag and drop is rare, so the button is the primary path.

Theming

Dragging uses --color-accent-subtle + accent border; invalid uses danger tokens.

Accessibility

Role and pattern

Visually hidden <input type="file" accept=".csv"> triggered by the labelled button; drop is a pointer-only enhancement (2.5.7 has the button alternative).

Keyboard

KeyAction

Button “Choose CSV file”; errors are shown in an Alert (role=alert) above, as in guest-import-alert.
