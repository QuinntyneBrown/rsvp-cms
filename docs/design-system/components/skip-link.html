Skip link

The skip link is the first thing a keyboard user reaches on every page. It stays out of sight until focused, then jumps straight to the page's main content, past the sidebar and top bar.

WCAG 2.2 AAStatus: stableWCAG 2.4.1 Bypass blocks

Overview

All 166 mocks start with <a class="skip-link" href="#main">Skip to content</a>, and every one has a <main id="main"> for it to land on. On an organiser page from 48rem, where the sidebar is persistent, it skips 9 tab stops (the sidebar's 6 links, then search, notifications and account) before the breadcrumb. This page has one too: press Tab from the top.

  • One skip link per page, always first in the DOM, always to #main.
  • Don't add more skip links for sections; headings and landmarks already let screen-reader users jump.

Anatomy

  1. ContainerRaised surface, --shadow-3, --radius-md, 8 × 16px padding.
  2. Label“Skip to content”, --text-label.

Variants

Skip to content
Shown in its focused state. .skip-link--static keeps it in flow for documentation; in a page it is absolutely positioned at the top left.
HTML
<a class="skip-link skip-link--static" href="#main" data-state="focus">Skip to content</a>

There is one variant. The same link works in every shell (app, public, auth) because every shell names its main region #main.

Sizes

One size: label text with 8 × 16px padding.

States

Two states: off-screen (above the viewport, top: -6rem) and focused (16px from the top-left corner, over everything at --z-tooltip). There is no hover state while hidden, because it cannot be pointed at.

Responsive behaviour

  • Identical at every width: 16px from the top-left corner, above the sticky top bar.
  • It never shifts the layout; it slides over the page.

Theming

Raised surface (--color-bg-surface-raised) with default text and --shadow-3, so it reads as a floating chip over both the light top bar and the dark one.

Accessibility

Role and pattern

A same-page link (<a href="#main">), WCAG 2.4.1. The target <main id="main"> takes focus natively when it is the fragment target; add tabindex="-1" to <main> if a router intercepts the hash.

Keyboard

KeyAction
TabFirst press on a page focuses and reveals the skip link.
EnterMoves focus to the start of main content; the next Tab is the first control inside it.
Tab againSkips it: the link slides away and focus moves to the next control.

Focus

The standard focus ring around the revealed chip. scroll-padding-top keeps the landing point clear of the sticky top bar.

Labelling

The text is the name: “Skip to content”. No aria-label.

Motion

Slides down over --duration-fast; appears at once under reduced motion.

Touch

Never visible without a keyboard. Under (pointer: coarse) (a tablet with a keyboard) it is at least 44px tall (L2-084).

Content

  • “Skip to content”, sentence case, on every page. Not “Skip navigation” (on guest pages there is no navigation to skip).
