ErrorState

Replaces content that failed to load, and the full-page 404, 403, 500, offline and invalid-invitation pages.

WCAG 2.2 AAStatus: stableReact: ErrorState

Overview

Same anatomy as EmptyState with the danger (or warning) icon, a recovery action and, for 500, a reference. In-page (a table or card failed) it is compact; as a page it uses the auth shell and an h1.

Anatomy

  1. IconDanger circle.
  2. TitleWhat happened, in plain words.
  3. TextWhat is safe + reference.
  4. ActionsRetry first, then a way out.

Variants

We couldn’t load your guests

Check your connection and try again.

In-page (compact).

Page not found

The page may have moved. Check the address or go back to your events.

404.

You don’t have access to this event

Ask the organiser to add you as a co-host.

403.

You’re offline

We’ll keep trying. Changes you make now won’t be saved.

Offline.

This invitation link has expired

Ask Priya Natarajan for a new link.

Contact the host
Invalid / expired invitation (guest).

Sizes

We couldn’t load your guests

Try again.

Compact in-page; full page uses the full size inside the auth shell.
