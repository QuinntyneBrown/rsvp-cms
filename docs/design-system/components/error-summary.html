ErrorSummary

On a failed submit, a box at the top of the form lists every error as a link to its field and receives focus (L2-087).

WCAG 2.2 AAStatus: stableReact: ErrorSummary

Overview

Shown after submit when one or more fields are invalid. It takes focus (tabindex="-1"), its heading says how many things to fix, and each item links to the field (activating the link focuses the field). Field-level errors stay next to each field. Server failures that are not about a field use Alert.

Anatomy

  1. IconWarning, decorative.
  2. HeadingCount: “2 things to fix”.
  3. ListOne link per error, same text as the field error.
  4. Accent edge4px --color-danger-solid left border.

Responsive behaviour

  • Full width at every breakpoint; inside dialogs it sits at the top of the body and the body scrolls to it.

Theming

Danger alert tokens plus --color-danger-solid edge.

Accessibility

Role and pattern

A focusable region (tabindex="-1") labelled by its heading; links are native anchors to field ids. Live-region decision: the summary does not carry role="alert", because moving focus to it already makes screen readers read it; adding alert would announce it twice. Every other error that appears without moving focus uses role="alert" (assertive).
