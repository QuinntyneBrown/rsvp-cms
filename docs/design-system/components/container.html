Container

Centres page content and applies the page margins: default (organiser, 1280px), narrow (auth and RSVP, 672px) and guest (event page, 672px below LG, 960px from LG).

WCAG 2.2 AAStatus: stableReact: ContainerLayout

Overview

Container is the only thing that sets page side margins (--layout-margin: 16px < MD, 32px MD, 48px LG+). Guest page layout decision (576–991px): single column — every block stacks, Container narrow width (max 672px) centred, side margins --layout-margin (16px at SM, 32px at MD), RSVP form full width of the column. From 992px Container guest (960px) and Details + Schedule sit side by side; RSVP form max --layout-form-max (720px).
