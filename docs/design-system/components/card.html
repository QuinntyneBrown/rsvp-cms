Card

The surface that groups related content: form sections, stats, page blocks, the auth box. Interactive cards are buttons (the block picker).

WCAG 2.2 AAStatus: stableReact: Card

Overview

Variants: default (padding 24px), flush (no padding; lists and tables inside), sunken (the “well” used for the page preview), interactive (whole card is one <button> with aria-pressed for selection). Header and footer are optional parts.

Anatomy

  1. HeaderTitle (--text-h4) + caption + actions.
  2. BodyAny content.
  3. FooterTop border, right-aligned actions.
  4. Surface--color-bg-surface, 1px default border, --radius-lg, --shadow-1.

Responsive behaviour

  • Full width below MD; Grid places cards from MD.
  • Padding stays 24px; on 360px screens flush cards hold tables that scroll inside.

Theming

Dark theme: surface gray-900 on canvas gray-950, darker shadow; selected uses accent subtle.

Accessibility

Role and pattern

Non-interactive card: div or section aria-labelledby (title id). Interactive card: one <button>; no nested interactive content.
