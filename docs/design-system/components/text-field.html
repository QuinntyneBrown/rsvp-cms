TextField

Single-line text entry: names, emails, passwords, invitation codes, dates and times.

Overview

Use for short free text. Pick the right type and autocomplete so phones show the right keyboard and password managers work: email + autocomplete="email", password + current-password/new-password, date/time for the invite window. Always inside a Field.

Anatomy

  1. Container40px, 1px --color-border-strong, --radius-md, --color-bg-surface.
  2. Value--text-body 16px (no iOS zoom).
  3. Padding--space-2 × --space-3.

Variants

The code is on your invitation email, like MAYA-7K2Q.
Text, email, password, code, date, time.

Sizes

sm 32px (dense filters), md 40px (default), lg 48px (guest invitation code).

Responsive behaviour

  • Full width of its Field at every breakpoint.
  • Font stays 16px so iOS does not zoom.
  • Under (pointer: coarse) the hit area grows to --target-comfortable (44 × 44 px, L2-084); fine pointers keep the visual size, never below --target-min (24 px).

Theming

Component tokens: border --color-border-strong, hover border --color-fg-muted, focus border/ring --color-focus-ring, invalid --color-danger-solid (2px effective), disabled background --color-bg-subtle, read-only --color-bg-surface-sunken.

Accessibility

Role and pattern

Native <input> labelled by <label for>.

Keyboard

KeyAction
TabFocus.
TypingEdits; validation runs on blur, then re-validates on input once invalid.

Focus

Ring at offset 0 plus focus-coloured border so it reads inside dense forms.

Labelling

Via Field. autocomplete on personal data (1.3.5). Paste is never blocked (3.3.8).

Content

  • Invitation codes are case-insensitive and accept spaces; say so in help.
