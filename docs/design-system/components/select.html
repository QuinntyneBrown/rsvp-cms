Select

A native dropdown for one choice from a short, known list: group, meal, party size, sort order, time zone.

Overview

Use the native <select>; it is accessible and mobile-friendly. Use RadioGroup when there are 2–4 options that benefit from being visible (event type, attending). No custom listbox exists in this system.

Anatomy

  1. ContainerSame as TextField.
  2. ValueSelected option.
  3. ChevronCSS-drawn, currentColor, 18px from the right edge.

Variants

Pick one per guest.
Default, with placeholder option, small (table toolbars).

Sizes

32 / 40 / 48px.

Responsive behaviour

  • Full width of its Field.
  • Phones show the OS picker.
  • Under (pointer: coarse) the hit area grows to --target-comfortable (44 × 44 px, L2-084); fine pointers keep the visual size, never below --target-min (24 px).

Theming

Shares TextField tokens; the chevron uses currentColor.

Content

  • A placeholder option (“Choose a meal”) only when there is no sensible default.
