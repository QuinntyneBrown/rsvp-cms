AppShell

The frame of every organiser page: skip link, SideNav, Topbar, main content and the toast region. Guest pages use the public variant: Topbar with the event name, narrow content, Footer.

Overview

AppShell is layout only; it takes its parts as slots. Organiser (variant="organiser"): .sidebar-layout grid with SideNav + (Topbar, <main id="main"> in a Container). Guest (variant="public"): Topbar with the event title and host, main in a narrow/guest Container, Footer “Sent with Invitely”. Auth (variant="auth"): centred card (sign-in, forgot and reset password, error pages). Every variant renders SkipLink first and a polite toast region last.

Navigation layout (decision): XS < 576px — the menu IconButton opens the SideNav as a full-width panel over a backdrop; SM 576–767px — still collapsed behind the menu button; the panel opens as a left drawer --layout-drawer-width (320px) wide over a backdrop, page content keeps the full width with --layout-margin (16px) gutters; MD ≥ 768px — persistent SideNav (--layout-sidebar-width, 256px) beside the content, menu button hidden (L2-080).

Anatomy

  1. SideNavPrimary navigation; persistent from MD.
  2. TopbarMenu button (below MD), search, notifications, account.
  3. Main<main id="main"> Container with PageHeader.
  4. Toast regionFixed, polite live region.

Responsive behaviour

  • XS < 576px: SideNav hidden; menu button opens it full width over a backdrop; content gutter 16px (L2-080).
  • SM 576–767px: SideNav hidden; menu button opens a 320px (--layout-drawer-width) left drawer over a backdrop; content keeps 16px gutters. Decision for the L2 gap.
  • MD ≥ 768px: SideNav persistent at 256px; menu button hidden; 8 columns, 24px gutter, 32px margin.
  • LG ≥ 992px: 12 columns, 32px gutter, 48px margin. XL ≥ 1200px: content capped at --layout-container-max (1280px).
  • No horizontal page scroll from 360 to 1920px; wide tables scroll inside .table-wrap.
  • Guest shell: single column < 992px (Container narrow, 672px max); from 992px Container guest (960px) with Details and Schedule side by side (see Grid).

Theming

Canvas --color-bg-canvas; SideNav and Topbar on --color-bg-surface with --color-border-default edges.

Accessibility

Role and pattern

Landmarks: header (Topbar), nav aria-label="Primary" (SideNav), main id="main", footer; toast region role="status" aria-live="polite"; a second, empty role="alert" region for error toasts.

Keyboard

KeyAction
Tab (first)Skip to content (L2-086).
EscCloses the navigation drawer and returns focus to the menu button.
Tab in open drawerCycles inside the drawer (modal below MD).

Focus

Opening the drawer moves focus to its first link; closing returns it to the menu button. scroll-padding-top equals --layout-topbar-height so the sticky Topbar never hides the focused element (2.4.11).

Labelling

Navigation is “Primary”; the drawer is role="dialog" aria-modal="true" aria-label="Navigation" below MD, and a plain nav from MD.

Live ratios for the token pairs this component relies on, in both themes. Every pair is also listed in tokens/contrast-pairs.json and checked by check_contrast.py.
