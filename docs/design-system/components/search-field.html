SearchField

A text input with a leading magnifier and a visually hidden label, for filtering events, guests and responses, and for the topbar search.

WCAG 2.2 AAStatus: stableReact: SearchField

Overview

Use above a table or list to filter as you type (debounced 250 ms) and in the topbar inside <form role="search">. Results update in place; the result count is announced politely (“12 guests match”). For filters with fixed values use Chips.

Anatomy

  1. Hidden labelvisually-hidden label (“Search guests”).
  2. Icon20px search icon at --space-3, --color-fg-subtle, decorative.
  3. Inputtype=search, left padding --space-10.

Variants

Topbar (global) and table filters.

Sizes

One size (md). Coarse pointers raise it to 44px.

Responsive behaviour

  • Topbar: flexes to fill, max 28rem.
  • Above tables: full width below SM, auto width in the filter Cluster from SM.

Theming

Same tokens as TextField plus --color-fg-subtle for the icon.

Accessibility

Role and pattern

<input type="search">; the topbar instance sits in <form role="search"> (search landmark).

Keyboard

KeyAction
TypingFilters after 250 ms.
EscClears the query (native search behaviour).
EnterTopbar: submits; table filter: no-op.

Focus

Focus stays in the field while results update.

Labelling

Visually hidden label is required; placeholder is not the name. Result counts go to a polite live region.
