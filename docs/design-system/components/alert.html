Alert

A persistent message about the page or a section: event status banners, guest import results, sign-in failures, a dialog’s failed request, the guest page’s window notice.

WCAG 2.2 AAStatus: stableReact: Alert

Overview

Two layouts: inline (in the content flow, rounded, 4px status edge) and banner (full width at the top of the page, under the topbar: schedule banner and public banner). Four tones. Optional actions and dismiss. Use Toast for transient results.

Live-region rule: an Alert that appears as the result of an error uses role="alert" (assertive); one that reports a status change uses role="status" (polite); one present on page load has no live role.

Anatomy

  1. IconTone icon.
  2. TitleLabel font.
  3. TextBody.
  4. Actionssm Buttons or links.
  5. Edge4px left border in the tone’s border colour.

Responsive behaviour

  • Actions wrap under the text below SM.
  • Banners span the content width and stack their actions below SM.

Theming

Component tokens --alert-bg, --alert-fg, --alert-border, --alert-icon per tone.

Accessibility

Role and pattern

div with role="alert" (errors appearing after an action), role="status" (status changes) or none (present on load). APG Alert.
