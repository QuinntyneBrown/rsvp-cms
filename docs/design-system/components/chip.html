Chip

Toggle chips that filter a table by status: All, Attending, Declined, Waiting.

Overview

Filter chips are toggle buttons (aria-pressed) in a labelled group. The mocks use single-select (“All” or one status). Removable input chips are documented but not used yet.

Anatomy

  1. Container32px pill, strong border.
  2. Label--text-label.
  3. Count (optional)Muted, tabular.

Variants

Filter group (single select).
Family
Removable (input) chip.

Sizes

sm 24px, md 32px (default); 44px on coarse pointers.

States

DefaultHoverFocusDisabled
Off
Pressed

Responsive behaviour

  • The group wraps; below SM it scrolls horizontally inside its row if it would wrap to three lines.
  • Under (pointer: coarse) the hit area grows to --target-comfortable (44 × 44 px, L2-084); fine pointers keep the visual size, never below --target-min (24 px).

Theming

Pressed: --color-accent-subtle / --color-fg-accent / accent border.

Accessibility

Role and pattern

<button aria-pressed> in role="group" with aria-label (“Filter by reply”). Single-select logic: pressing one releases the others.

Keyboard

KeyAction
TabEach chip.
Enter/SpaceToggle; the table updates and the count is announced politely.

Focus

Shared ring.

Labelling

Counts are part of the name (“Waiting 23”).
