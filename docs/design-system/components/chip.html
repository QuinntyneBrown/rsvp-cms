Chip

Chips are small, rounded controls for filtering a list in place (All, Waiting, Attending, Declined) and for tags that can be removed. A pressed chip is a filter that is on.

WCAG 2.2 AAStatus: stable

Overview

Use filter chips for two to five mutually useful filters right above the table they filter; the guests, events and responses pages all use them. Use a select for longer option lists (“Sort by”), tabs to switch between sections, and a badge for status that is not interactive.

  • Filter: a <button aria-pressed> in a labelled group. The mocks use single-select filters (“All” plus one reply).
  • Removable (input): a tag with a labelled remove button, for a guest’s groups in the edit dialog.
  • Static: a non-interactive tag on a <span>; prefer a badge unless it sits among removable chips.

Anatomy

  1. Filter chip32px pill, --text-label, 1px --color-border-strong; pressed turns accent-subtle with an accent border.
  2. Tag labelThe group or value name.
  3. Remove button24px round button inside the chip, labelled “Remove Friends group”.

Responsive behaviour

  • Filter groups are a .cluster and wrap onto a second line at 360px; they never scroll sideways, so every filter stays visible.
  • Keep filter labels to one or two words so four chips fit on two lines at 360px.
  • On touch screens (pointer: coarse) every chip is 44px tall; with a mouse, medium chips are 32px. Small chips are for display-dense tags.

Theming

Chips read --color-bg-surface, --color-border-strong and --color-fg-default when off; --color-accent-subtle, --color-accent and --color-fg-accent when pressed — the same look as a pressed button and the current nav link, so “selected” looks the same everywhere. Height is the component token --chip-height.

Accessibility

Role and pattern

Filter chips are toggle buttons (APG Button with aria-pressed) inside role="group" with an aria-label (“Filter by reply”). They are not tabs and not radio buttons: pressing one filters the table below and leaves focus on the chip. Removable chips are text plus a separate <button>.

Keyboard

KeyAction
TabMoves to each chip and each remove button in order.
Enter, SpaceToggles a filter chip; activates a remove button.
Backspace / DeleteNot used: removal is always an explicit button.

Focus

The shared ring follows the pill shape. After a tag is removed, focus moves to the next tag’s remove button, or to the field that adds tags when none are left.

Labelling

The chip text is its name and aria-pressed its state (“Waiting, toggle button, pressed”). Announce the result count in a polite live region after filtering (“23 guests waiting”). Remove buttons name the tag: “Remove Friends group”.

Motion

Background and border fade over --duration-fast; instant with reduced motion.

Touch

Under (pointer: coarse) chips grow to 44px tall and remove buttons to 44 × 44px (--target-comfortable, L2-084); with a fine pointer chips are 32px and remove buttons 24px, the WCAG 2.5.8 minimum.

Content

  • Filter labels match the badge vocabulary: “Waiting”, “Attending”, “Declined”, and “All” first.
  • Sentence case, no counts in the label; show counts in the live-region announcement or the table caption.
  • Tag labels are the value itself (“Friends”), not “Group: Friends”.
