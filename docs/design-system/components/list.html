Overview

Use when items are read top to bottom rather than compared by column. Variants: static, interactive (the whole row is one link), with trailing action (“Mark read”), unread marker.

Anatomy

  1. Unread marker8px accent dot, decorative; hidden text “unread”.
  2. Title--text-label.
  3. MetaMuted small text.
  4. TrailingBadge or action.

Theming

Divider --color-border-default; hover --color-bg-subtle.
