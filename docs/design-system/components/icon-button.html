IconButton

A square button that shows only an icon: close a dialog, open navigation, notifications. Its name lives in aria-label and a tooltip.

WCAG 2.2 AAStatus: stableReact: IconButton

Overview

Use an IconButton where space is tight and the icon is unambiguous: Close (every dialog), Open navigation (topbar menu below MD), Notifications (topbar), Dismiss (toasts and alerts use a smaller close). If the icon needs explaining, use a Button with a label instead.

Anatomy

  1. Icon20px Icon, aria-hidden.
  2. ContainerSquare, --control-height-* wide and tall, --radius-md.
  3. Accessible namearia-label, mirrored by a Tooltip on hover and focus.

Variants

Ghost is the default; secondary and danger exist for isolated actions.

Sizes

sm 32px (cards, toasts) and md 40px (topbar, dialog header). 44px on coarse pointers.

States

Responsive behaviour

  • The topbar menu IconButton shows only below MD (768px), where navigation is a drawer.
  • Under (pointer: coarse) the hit area grows to --target-comfortable (44 × 44 px, L2-084); fine pointers keep the visual size, never below --target-min (24 px).

Theming

Shares Button’s component tokens; .btn--icon only changes geometry.

Accessibility

Role and pattern

Native <button> with aria-label. Toggles add aria-expanded + aria-controls (navigation menu).

Keyboard

KeyAction
TabFocus.
Enter, SpaceActivate.
EscCloses the overlay the button opened (navigation drawer, dialog).

Focus

Shared ring. After it closes a dialog or drawer, focus returns to the control that opened it.

Labelling

aria-label is required and names the action and object when needed: “Close”, “Open navigation”, “Notifications, 3 unread”. The tooltip repeats it visually; counts go in the label, not only the badge.

Motion

Same as Button.

Touch

40px default. Under (pointer: coarse) the hit area grows to --target-comfortable (44 × 44 px, L2-084); fine pointers keep the visual size, never below --target-min (24 px).

Content

  • Labels are verbs or nouns that name the action: “Close”, “Dismiss”, “Open navigation”.
  • Never rely on an icon for a destructive action without a confirmation step.
