Topbar

The sticky header bar: menu button below MD, search, notifications and account in the organiser app; event name and host on guest pages.

WCAG 2.2 AAStatus: stableReact: Topbar

Overview

One per page, sticky at the top (--z-sticky), --layout-topbar-height (56px) tall. Organiser order: menu IconButton (below MD), SearchField (form role=search), spacer, notifications IconButton with tooltip, account Avatar button. Public order: brand link with the event name, spacer, “From {host}”.

Anatomy

  1. Menu buttonBelow MD only; aria-expanded, aria-controls="primary-nav".
  2. SearchSearchField, max 28rem.
  3. NotificationsIconButton + Tooltip; count in name.
  4. AccountAvatar button.

Responsive behaviour

  • Below MD: menu button visible; search shrinks; nothing wraps.
  • From MD: menu button hidden (SideNav is persistent).
  • Public: event name truncates with ellipsis below SM; host line hides below 360px.

Theming

--color-bg-surface with --color-border-default bottom edge.

Accessibility

Role and pattern

<header> (banner landmark) with a role="search" form.
