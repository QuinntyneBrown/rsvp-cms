Grid

Places cards in responsive columns: auto-fill stat and event cards, a 12-column layout grid, the two-column guest page and the editor-with-preview split.

WCAG 2.2 AAStatus: stableReact: GridLayout

Overview

Variants: auto (cards min 18rem, fill the row), auto-sm (min 10rem; block picker), columns (the layout grid: 4/8/12 columns with token gutters), split (1 column, 2 equal from LG: guest Details + Schedule), aside (1 column, main + 22rem aside from LG: page editor + preview).

Anatomy

  1. Trackminmax(min(100%, 18rem), 1fr).
  2. Gutter--layout-gutter.

Responsive behaviour

  • auto: 1 column at 360px, 2 at MD, 4 at LG+ for stat cards.
  • split / aside: one column below 992px; two from 992px.
  • columns: 4 / 8 / 12 at XS / MD / LG.
