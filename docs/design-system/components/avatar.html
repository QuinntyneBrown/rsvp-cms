Avatar

An avatar is a small round marker for a person: Priya’s initials in the top bar, guests in a list, a stack of who is coming. It never carries information that is not also written next to it.

WCAG 2.2 AAStatus: stable

Overview

Use an avatar beside a person’s name, or as the trigger for the signed-in organiser’s account menu. Do not use avatars for events or groups; use an icon or a badge.

  • Initials (the only kind in the mocks): two letters, first and last name.
  • Icon: a person icon when the name is unknown, such as an imported row without a name.
  • Image: a photo, cropped square to a circle; falls back to initials if it fails to load.
  • Group: overlapping avatars with a “+49” overflow, for who is attending.
  • Button: button.avatar, the account menu trigger in the top bar.

Anatomy

  1. InitialsTwo letters, --text-label, --color-fg-accent; scaled with the size.
  2. ContainerCircle (--radius-full) on --color-accent-subtle; 32, 40 or 56px.

Responsive behaviour

  • Sizes do not change with the breakpoint; the top bar always uses small.
  • Groups show at most four avatars including the overflow at every width; the overflow count grows instead.
  • The account button is 32px visually; on coarse pointers its hit area is 44 × 44px.

Theming

Reads --color-accent-subtle and --color-fg-accent; the overflow avatar uses --color-bg-subtle and --color-fg-muted. Size is the component token --avatar-size. In dark, the accent-subtle background becomes blue-950 and the initials blue-300.

/* A larger avatar for a profile header */
.profile .avatar { --avatar-size: 4rem; }

Accessibility

Role and pattern

A decorative <span aria-hidden="true"> when the name is written next to it; an <img alt="Mei Rodríguez"> when it stands alone; a <button> following the APG Menu Button pattern when it opens the account menu.

Keyboard

KeyAction
TabReaches the account button only; static avatars are skipped.
Enter, Space, ↓Opens the account menu and moves focus to its first item (see menu).

Focus

The shared ring follows the circle. When the menu closes, focus returns to the avatar button.

Labelling

The account button is named “Account menu for Priya Natarajan”, not “PN”. A group has role="img" and an aria-label that lists the first names and the overflow count.

Motion

The hover ring fades in over --duration-fast.

Touch

The account button looks 32px but, under (pointer: coarse), an invisible ::after extends its hit area to 44 × 44px (--target-comfortable, L2-084) without moving the layout.

Content

  • Initials are the first letters of the first and last name, uppercase: Priya Natarajan → “PN”, Mei Rodríguez → “MR”.
  • One-word names use one letter; never three letters.
  • The overflow reads “+49”, and its label says “and 49 more”.
