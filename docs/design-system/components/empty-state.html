EmptyState

What a list or page shows when there is nothing yet, or nothing matches: no events, no guests, no replies, no notifications, no search results.

WCAG 2.2 AAStatus: stableReact: EmptyState

Overview

Icon, title, one sentence, one primary action (first run) or a reset action (no results). Compact inside cards and tables; full on pages.

Anatomy

  1. Icon64px accent-subtle circle.
  2. Title--text-h3.
  3. TextMuted, max 36ch.
  4. ActionsOne primary, optional secondary.
