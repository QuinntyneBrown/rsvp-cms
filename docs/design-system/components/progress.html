Progress

A progress bar shows a measurable proportion: 73% of invitees have replied, 60% of the CSV is imported. When the end is unknown, the bar moves without a value.

WCAG 2.2 AAStatus: stablerole="progressbar"

Overview

Use a determinate bar when you know the total: replies received out of invitees, rows imported out of rows. Use an indeterminate bar for a wait longer than about a second whose length is unknown, such as reading an uploaded file. For a short wait inside a button or a small region use a spinner; while a page’s content loads use a skeleton.

  • Determinate: the event overview’s “Replies received 73%”, the import’s 60%.
  • Indeterminate: “Reading file” while the guest import parses the CSV.
  • Success / danger: the finished state of a task bar (import complete; import stopped).

Anatomy

  1. LabelVisible name, also the accessible name via aria-labelledby.
  2. ValuePercent, tabular figures.
  3. Fill--color-accent, width from --value.
  4. Track8px, fully rounded, --color-bg-subtle-hover.

Setting the value

The fill width is the custom property --value, set inline on .progress__bar, exactly as the mocks do. Keep it in step with aria-valuenow; script updates both together.

Sizes

One height (8px, --progress-height). Override the component token for a thinner bar inside a toast or table cell.

  • Reduced motion: the indeterminate bar stops sliding and shows a full, 60% opaque fill.
  • Progress has no hover or focus state; it is not interactive.

Responsive behaviour

  • The bar fills its container at every width; the label and value sit on one line and wrap only if the label is long.
  • Value text never shrinks below the caption size.

Theming

Track --color-bg-subtle-hover, fill --color-accent, or --color-success-solid / --color-danger-solid for finished states. Height and fill come from --progress-height and --value. The fill keeps at least 3:1 against the track in both themes.

Accessibility

Role and pattern

role="progressbar" with aria-valuenow, aria-valuemin="0" and aria-valuemax="100"; indeterminate bars omit aria-valuenow. Named by the visible label through aria-labelledby. The region being filled carries aria-busy="true" until it finishes.

Keyboard

KeyAction
TabNot focusable; the label and value are read in reading order.

Focus

Starting or finishing never moves focus. When an import finishes, the result appears in an alert in the same place.

Labelling

The label says what is progressing (“Replies received”, “Reading file”). Do not announce every percent: the region announces start and finish only.

Motion

Width changes over --duration-slow; the indeterminate slide loops every --duration-shimmer. Reduced motion freezes both.

Touch

Not interactive.

Content

  • Label the thing, not the act of waiting: “Replies received”, “Importing 84 rows”.
  • Show the number the person cares about next to the bar: 73%, or “61 of 84”.
  • Finished labels state the result: “81 guests imported”.
