Stepper

Shows progress through a multi-step flow: new event (Details, Invite window, Page) and guest import (Upload, Map columns, Review, Done).

WCAG 2.2 AAStatus: stableReact: Stepper

Overview

Informational, not navigation: steps are not links. The current step has aria-current="step"; completed steps show a check and hidden “(complete)”.

Anatomy

  1. Marker28px circle with the number, check when complete.
  2. Label--text-label; hidden below MD except current.
  3. CurrentAccent fill.

Variants

  1. Details
  2. Invite window
  3. Page
Event creation.
  1. Upload (complete)
  2. Map columns (complete)
  3. Review
  4. Done
Guest import.

Sizes

One size.

Responsive behaviour

  • Below MD only the current label shows; others keep their numbers (labels visually hidden, still read).

Theming

Current: accent; complete: success-fg fill with inverse check.
