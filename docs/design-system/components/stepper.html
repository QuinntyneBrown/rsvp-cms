Stepper

A stepper shows how far through a fixed sequence the organiser is: the guest CSV import (Upload, Map columns, Review, Done) and creating an event (Details, Invite window, Page).

Overview

Two flows in the mocks use it: guest import (6 states plus 4 import alerts) and new event (5 states). It is information, not navigation: steps are not links, and the flow's own buttons move between them.

  • Use it for three to five steps that always happen in the same order.
  • Don't use it for a single long form; use fieldsets. Don't use it for location in the app; that is the breadcrumb.

Anatomy

  1. Marker28px circle, 2px border: number upcoming, tick complete, accent fill current, “!” error.
  2. Label--text-label; muted upcoming, accent current.
  3. Current steparia-current="step"; the only label shown on phones.

Sizes

One size: 28px markers with label text.

States

Each step is upcoming, current, complete or in error. Complete and error carry visually hidden text so the state is not colour or icon alone.

Responsive behaviour

  • Base (phones): markers only, with the current step's label beside its marker. Hidden labels stay in the accessibility tree.
  • 48rem (--layout-breakpoint-md) and up: every label shows.
  • The vertical variant always shows labels and descriptions.
  • Mobile first: this replaces the mocks' max-width: 47.99rem query with a base rule and a min-width: 48rem override.

Theming

Upcoming markers use --color-border-strong; current fills with --color-accent and --color-fg-on-accent; complete fills with --color-success-fg and a --color-fg-inverse tick; error with --color-danger-solid. All pairs are in contrast-pairs.json.

Accessibility

Role and pattern

An ordered list (<ol aria-label="Progress">), so position and count are announced (“list, 4 items”). The current step has aria-current="step". Numbers are CSS counters; ticks and “!” are generated content.

Keyboard

KeyAction
TabNothing to focus: steps are not interactive. Focus goes to the flow's own buttons (Back, Continue).

Focus

When the flow advances, focus moves to the new step's heading, not to the stepper.

Labelling

Completed steps end with visually hidden “(completed)”, errored ones “(has errors)”, so “Upload (completed)” is read; the tick alone would be silent.

Motion

None; state changes are instant.

Content

  • One or two words per step, nouns or verbs consistently: “Upload”, “Map columns”, “Review”, “Done”.
  • The last step names the outcome (“Done”), not “Finish”.
  • Descriptions, when used, say what the step covers in under six words.
