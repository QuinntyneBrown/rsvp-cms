VisuallyHidden

Text for screen readers only: table captions, search labels, “unread”, the object of a repeated row action.

WCAG 2.2 AAStatus: stableReact: VisuallyHidden

Overview

Clips content to 1px while keeping it in the accessibility tree. Never hide focusable elements with it (use SkipLink for that pattern).
