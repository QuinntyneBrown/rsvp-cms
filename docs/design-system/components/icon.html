Overview

Icons support labels; they never carry meaning alone. Decorative by default (aria-hidden="true"). The full sheet is on the iconography page.

Anatomy

  1. Glyph24-unit viewBox, 2px stroke, currentColor.
  2. Box20px default.

Variants

A selection; names in the iconography foundation.

Sizes

sm 16, md 20, lg 24px.

Theming

currentColor; status icons take --color-{status}-icon.

Inline <svg aria-hidden="true">; meaningful standalone icons get role="img" + aria-label (rare; prefer IconButton labels).
