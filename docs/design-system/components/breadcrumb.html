Breadcrumb

The breadcrumb shows where a page sits (Dashboard / Events / Guests / Import CSV) and gives one-click routes back up. On phones it becomes a single back link to the parent.

Overview

95 organiser mocks open <main> with a breadcrumb: every page below the top level (event pages, guest import, new event, settings). Dashboard, Events and Notifications are top-level and have none.

  • Use it when a page is two or more levels deep.
  • The last item is the current page, as text with aria-current="page", not a link.
  • Don't use it for steps in a flow; that is a stepper. Don't use it as the only way back from a dialog.

Anatomy

  1. Ancestor linkMuted, no underline until hovered; --text-body-sm.
  2. Separator“/” in --color-fg-subtle, drawn by CSS so screen readers skip it.
  3. Current page--color-fg-default, medium weight, aria-current="page".

Responsive behaviour

  • Base (phones): only the parent item shows, as “‹ Guests”, a back link. The current page is already the <h1> directly below, so nothing is lost. The trail can never wrap, however long an event name is.
  • 48rem (--layout-breakpoint-md) and up: the full trail, wrapping if it must (flex-wrap), with “/” separators.
  • The collapse is CSS only (:nth-last-child(2)); the markup is the same at every width.

Theming

Links use --color-fg-muted, hover and current --color-fg-default, separators --color-fg-subtle. No backgrounds, so the breadcrumb reads correctly on canvas or surface in both themes.

Accessibility

Role and pattern

The APG Breadcrumb pattern: <nav aria-label="Breadcrumb"> around an ordered list; the current item carries aria-current="page". Separators are CSS generated content, not text.

Keyboard

KeyAction
TabMoves through the ancestor links; the current page is not focusable.
EnterFollows the link.

Focus

The standard ring around each link.

Labelling

The landmark is named “Breadcrumb”. On phones the single link is read “‹ Guests”; the “‹” is generated content, so it is announced only by some screen readers, and the link text alone still makes sense.

Motion

None.

Touch

Links are inline text at 14px; the phone back link is the only one shown there, with nothing within 24px of it, which satisfies the target-spacing exception of WCAG 2.5.8.

Content

  • Each item is the page's own title, shortened only if the title is a sentence (“Dashboard”, not “Good morning, Priya”).
  • Event names in full: “Maya’s 30th birthday”.
  • Start at Dashboard. Never include the product name.
