RadioGroup

One choice from a small visible set: will you attend, event type.

WCAG 2.2 AAStatus: stableReact: RadioGroup

Overview

Use for 2–5 mutually exclusive options that people should compare at a glance. Over five, use Select. The RSVP answer is a RadioGroup so both answers are visible.

Anatomy

  1. Legend--text-label; the group name.
  2. Option20px round input + label.
  3. Gap--space-2 between options.

Responsive behaviour

  • Horizontal groups stack below SM when options do not fit.
  • Under (pointer: coarse) the hit area grows to --target-comfortable (44 × 44 px, L2-084); fine pointers keep the visual size, never below --target-min (24 px).

Theming

Same tokens as Checkbox; card style adds --color-accent-subtle when checked.

Accessibility

Role and pattern

Native radios in <fieldset>/<legend>. APG Radio Group behaviour comes free.
