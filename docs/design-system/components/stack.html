Stack

Spaces children along one axis with a token gap: vertical stacks (forms, cards) and horizontal clusters (button rows, filters).

WCAG 2.2 AAStatus: stableReact: StackLayout

Overview

Replaces margins between siblings. direction="column" maps to .stack (gap 16px; sm 8px; lg 32px); direction="row" maps to .cluster (wraps, gap 12px, align centre; justify="between|end").
