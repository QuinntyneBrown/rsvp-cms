Field

The wrapper every form control sits in: label, optional marker, control, help text, error and counter, in a fixed order and spacing.

Overview

Every TextField, Select, Textarea and SearchField renders inside a Field. Groups of choices (RadioGroup, checkbox groups) use <fieldset>/<legend> with the same help and error parts. Field owns the ids: it links help and error to the control through aria-describedby and sets aria-invalid (L2-087).

Anatomy

  1. Label--text-label; “(optional)” suffix in --color-fg-subtle. Required is the default and is not marked.
  2. ControlAny input; full width of the field.
  3. Help--text-body-sm, --color-fg-muted.
  4. Error--color-danger-fg with a ⚠ marker so colour is not the only cue.
  5. Gap--space-1 between parts.

Field has no size; the control inside it does (sm, md, lg).

Responsive behaviour

  • Fields are full width in one column below MD; from MD only short related fields pair up (invite window open and close date) via Grid.
  • Label stays above the control at every width; no side labels.

Theming

Reads semantic tokens only; the control’s border tokens are documented on each input page.

Accessibility

Role and pattern

<label for> + control; groups use <fieldset>/<legend>.

Keyboard

KeyAction
TabMoves to the control; the label, help and error are not focusable.
Click on labelFocuses the control.

Focus

The control shows the focus ring; on submit with errors focus goes to the ErrorSummary, whose links focus each field.

Labelling

Visible label always (placeholders are hints). aria-describedby lists help then error ids. Errors are not live regions: they are read when the field is focused, and the summary announces the batch. Required is the default; optional fields say “(optional)”.

Live ratios for the token pairs this component relies on, in both themes. Every pair is also listed in tokens/contrast-pairs.json and checked by check_contrast.py.

Content

  • Labels are nouns: “Email”, “Party size”, “Message for Maya”.
  • Help says what or why in one sentence: “Allergies and anything the kitchen must know.”
  • Error formula: what to do, with an example: “Enter an email like name@example.com.”
  • Counters read “0 of 280”.

React

Implemented as src/shared/ui/components/Field/Field.tsx and exported from the components/index.ts barrel. Presentational only: data in through props, actions out through callbacks; variants, sizes and states are props, never caller class names.

PropTypeDefaultNotes
labelReactNode—Required visible label.
optionalbooleanfalseAdds “(optional)”.
helpReactNode—Help text.
errorstring—Error text; sets aria-invalid on the control.
counter{ value: number; max: number }—Renders “n of max”.
idstringautoControl id; help/error ids derive from it.
children(ids) =&gt; ReactNode | ReactElement—The control; Field injects id, aria-describedby, aria-invalid.
