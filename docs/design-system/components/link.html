Link

Text links move people to another page or anchor: “Forgot password?”, “Download the CSV template”, breadcrumbs.

WCAG 2.2 AAStatus: stableReact: Link

Overview

Links navigate; they never submit or change data. Inline links are always underlined (not colour alone, 1.4.1). Use Button with href when a navigation action needs button emphasis.

Anatomy

  1. TextUnderlined, --color-fg-link, 0.15em offset.
  2. Hover--color-fg-link-hover, 2px underline.

Responsive behaviour

  • Links wrap with their sentence; long URLs use overflow-wrap: anywhere.
  • Standalone links on coarse pointers get a 44px tall hit area (breadcrumb, footer).

Theming

Reads --color-fg-link and --color-fg-link-hover; dark theme uses blue-300/200.

Accessibility

Role and pattern

Native <a href>.

Keyboard

KeyAction
TabFocus.
EnterFollow.

Focus

Shared ring with 2px offset.

Labelling

Link text makes sense alone (“Download the CSV template”, not “here”). External links add hidden “(opens in a new tab)”.

Motion

Touch

Inline links are exempt from 2.5.8 when inside a sentence; standalone links get 44px on coarse pointers.

Content

  • Describe the destination: “View public page”, “Download the CSV template”.
  • Sentence case, no trailing punctuation unless it is a question (“Forgot password?”).
