Overview

Shown in an auto Grid of cards on the dashboard and event overview. Tabular numbers. Optional delta with arrow and sign.

Anatomy

  1. Label--text-label, muted.
  2. Value--text-h2, tabular.
  3. Delta (optional)Success/danger text with arrow.
