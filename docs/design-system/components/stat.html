Component · Data display

Stat

A stat is one number with a label, read at a glance: 84 invitees, 52 attending, 23 waiting. A row of stats opens the dashboard, the event overview and the responses page.

WCAG 2.2 AAStatus: stable

Overview

Use stats for the three to five numbers an organiser checks first. Use a progress bar for a share of a whole (73% replied), a table for numbers that need comparing across records, and plain text for numbers inside a sentence.

  • Card stat (.card.stat): label above a large tabular number, in a grid of equal cards.
  • With delta: a change since a stated time, with an arrow, a sign in words and colour.
  • Inline (.stat--inline): label and a smaller number on one line, for summaries inside a card or banner.

Anatomy

  1. Label--text-label in --color-fg-muted; says what is counted.
  2. Value--text-h2 (30px semibold), font-variant-numeric: tabular-nums.
  3. Delta (optional)--text-body-sm; success or danger colour plus an arrow and words.

Responsive behaviour

  • .grid--stats fits as many 10rem cards as the width allows: one per row at 360px (two need 336px), two or three per row on large phones and tablets, and all four in one row from 62rem (--layout-breakpoint-lg).
  • Labels wrap to two lines rather than truncate; values never wrap.
  • Card padding stays 24px; on phones the grid gutter is 16px.

Theming

Reads --color-fg-muted for the label, --color-fg-default for the value and --color-success-fg / --color-danger-fg for deltas. The card supplies the surface. No component tokens: a stat is typography.

Accessibility

Role and pattern

Plain text inside a labelled <section> (“Summary”). The label comes first in the DOM, so screen readers read “Attending so far, 82”. A delta reads as words (“6 since Friday”); the arrow is aria-hidden.

Keyboard

KeyAction
TabNot focusable. If a stat links to its detail, wrap the whole card in one link.

Focus

None, unless the card is a link; then the card shows the shared ring.

Labelling

The label names the count, including scope: “Invitees across events”, not “Total”. Loading uses a visually hidden “Loading summary” and aria-busy on the section.

Motion

Values do not count up. The loading skeleton shimmers and stops under reduced motion.

Touch

Not a target.

Content

  • Labels say what and where: “Attending so far”, “Waiting for a reply”, “Emails scheduled”.
  • Values are whole numbers with thousands separators (“1,204”); no units in the value, put them in the label.
  • Deltas say the period: “6 since Friday”, never a bare “+6”.
  • Zero is “0”, not “—”; a zero is information.
