Switch

An on/off setting that takes effect immediately: email me when someone replies, daily summary, invite-closing warning.

WCAG 2.2 AAStatus: stableReact: Switch

Overview

Use for preferences that apply as soon as they change and confirm with an InlineStatus (“Saved”). Use Checkbox inside forms that need a Save.

Anatomy

  1. Track44 × 24px, --radius-full; --color-border-strong off, --color-accent on.
  2. Thumb20px, --color-bg-surface, --shadow-1.
  3. LabelDescribes the setting, not the action.

Variants

Label right (default), with description.

Sizes

One size.

States

DefaultFocusDisabled
Off
On

Responsive behaviour

  • Label wraps; the track stays aligned to the first line.
  • Under (pointer: coarse) the hit area grows to --target-comfortable (44 × 44 px, L2-084); fine pointers keep the visual size, never below --target-min (24 px).

Theming

Track off --color-border-strong, on --color-accent; thumb --color-bg-surface.

Accessibility

Role and pattern

<input type="checkbox" role="switch"> in a label. APG Switch.
