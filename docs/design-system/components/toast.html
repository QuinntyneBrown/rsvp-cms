Toast

A brief message after an action: Changes saved, Invite window updated (with Undo), Couldn’t save. Appears bottom right, never steals focus.

WCAG 2.2 AAStatus: stableReact: Toast

Overview

Use for the result of an action the person just took. Use Alert for conditions that persist (page not published), and inline errors for forms.

Live-region politeness (decision): success, info and warning toasts and status messages render into the shell’s role="status" aria-live="polite" region — announced without moving focus (L2-087 AC4). Danger (error) toasts render into a separate role="alert" region (assertive) and never auto-dismiss. The same rule applies everywhere: status → polite; errors → role="alert".

Anatomy

  1. Status icon--color-{tone}-icon-on-inverse.
  2. TitleLabel font.
  3. TextBody small.
  4. Action (optional)Underlined text button: Undo, View, Retry.
  5. DismissLabelled close.
  6. Timer2px bar, decorative.

Responsive behaviour

  • XS < 576px: full width, 16px from the edges, bottom, above the safe area.
  • SM+: 24rem wide, bottom right, 24px inset.
  • Stacks newest at the bottom; at most 3 visible.

Theming

Inverse surface (dark in light theme, light in dark theme). Status icons use the on-inverse tokens added for this system so they keep ≥ 3:1 in both themes.

Accessibility

Role and pattern

Rendered inside the polite role="status" region (success/info/warning) or the role="alert" region (danger). Not a dialog; never takes focus.

Keyboard

KeyAction
TabReaches the action and Dismiss in document order at the end of the page (regions follow main).
EscWhen focus is inside a toast: dismiss it.

Focus

Never moves focus. Hover or focus inside pauses the timer (2.2.1).

Labelling

Dismiss “Dismiss”; action buttons are verbs.

Contrast

Motion

Entrance (decision): slides up 16px and fades in over --duration-base (200ms) with --ease-enter; leaves over --duration-fast (120ms) with --ease-exit. Instant under reduced motion. Auto-dismiss after 8s for success/info, 12s with an action; warnings and errors persist until dismissed.

Touch

Dismiss 24px on fine pointers, 44px on coarse.

Content

  • Title: past-tense result (“Changes saved”, “Guest added”).
  • Errors: what failed + what to do (“Couldn’t save. Check your connection and try again.”).
