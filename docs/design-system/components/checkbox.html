Checkbox

A checkbox turns one independent option on or off: keep me signed in, include this guest, email me about bounces. Several checkboxes in a group can all be on at once.

WCAG 2.2 AAStatus: stableNative <input type="checkbox">

Overview

Use a checkbox when each option stands alone and the choice is applied when the form is submitted. Use a radio group when exactly one option must win, and a switch when the setting takes effect the moment it changes.

  • Single: one option beside its label, such as “Keep me signed in” on sign-in.
  • Group: related options in a <fieldset> with a <legend> that asks the question.
  • With description: a second line in <small> explains the consequence.
  • Row selection: a bare input.checkbox in the first column of the guests and events tables, labelled by aria-label; the header checkbox selects all and shows indeterminate when some rows are selected.

Anatomy

  1. Box20px square, --radius-xs, 1px --color-border-strong; checked fills with --color-accent and a --color-fg-on-accent tick.
  2. LabelBody text; clicking it toggles the box because the input sits inside the <label>.
  3. Description (optional)<small> in --color-fg-muted, part of the label so it is read with it.

Sizes

Checkboxes have one size: a 20px box inside a row at least 24px tall (--target-min). Density changes the gap between rows, never the box.

States

Value (unchecked, checked, indeterminate) and interaction state combine. Pointer and focus states are forced with data-state; indeterminate can only be set from script (input.indeterminate = true), so it is forced with data-state="indeterminate" here.

Both themes

  • Hover darkens the border to --color-fg-muted; on a checked box the fill moves to --color-accent-hover.
  • Invalid adds aria-invalid="true" and a 2px danger edge. Use it for a required consent box; put the message under the group with .field__error.
  • Disabled greys the box and the label and removes it from the tab order. Explain nearby why it is unavailable.
  • Indeterminate only appears on a “select all” box whose children are partly selected. Activating it selects every row.

Responsive behaviour

  • Groups stay one column at every width; options never sit side by side because labels of different lengths become hard to scan.
  • The whole label is the target, so each option is at least 24px tall and as wide as its text; on phones the label wraps under itself, never under the box.
  • In tables the selection column stays first and 1px wide (.col-select) so the checkbox is still visible when the table scrolls sideways at 360px.

Theming

The box reads --color-bg-surface, --color-border-strong, --color-accent, --color-accent-hover and --color-fg-on-accent, plus --choice-size for the box. A theme changes the accent; the tick follows automatically because it is --color-fg-on-accent.

/* Larger boxes for a kiosk theme */
[data-theme="kiosk"] .choice input { --choice-size: 1.5rem; }

In dark the accent becomes blue-300 and the tick turns blue-950, keeping the tick above 7:1 against the fill.

Accessibility

Role and pattern

Native <input type="checkbox">, restyled with appearance: none so the browser still reports role, name and state. Groups use <fieldset> and <legend>. See the APG Checkbox pattern; the native element already satisfies it, including mixed state through indeterminate.

Keyboard

KeyAction
Tab / Shift+TabMoves to the next or previous checkbox; each box is its own tab stop.
SpaceToggles the focused box. On an indeterminate “select all”, selects every row.
EnterSubmits the surrounding form; it does not toggle.

Focus

The shared 2px ring with a 2px offset draws around the box, not the label, on :focus-visible.

Labelling

The input sits inside its <label>. Row-selection boxes have no visible label, so each carries aria-label="Select Jonah Adeyemi"; the header box is “Select all guests”. A group's error is linked with aria-describedby on the fieldset, and each box gets aria-invalid="true".

Motion

Fill and border change over --duration-fast; reduced motion makes the change instant through the tokens.

Touch

The label is part of the target, so a single option is at least 24px tall and usually much wider. Do not shrink the row with min-height: 0, as the sign-in mock did.

Content

  • Write the label as the thing that becomes true when checked: “Email me when someone replies”, not “Don’t email me”.
  • Sentence case, no full stop, no “Yes, I want to…”.
  • Put the consequence in the description, not the label: “Each person gets a personal link”.
  • The legend asks the question the group answers: “Send these emails to Priya”.
  • Name row checkboxes after the row: “Select Mei Rodríguez”, never just “Select”.
