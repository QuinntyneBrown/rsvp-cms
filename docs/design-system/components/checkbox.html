Checkbox

An independent on/off choice in a form, or row selection in a table.

WCAG 2.2 AAStatus: stableReact: Checkbox

Overview

Use for a choice that is saved with the form (“Keep me signed in”, “Send a reminder”) and for selecting table rows. Use Switch for settings that apply immediately. Groups sit in a <fieldset>.

Anatomy

  1. Box20px, --radius-xs, 1px strong border; checked fills with --color-accent.
  2. Label--text-body; clicking it toggles.
  3. Description (optional)--text-body-sm muted.

Variants

Include in export
Single, with description, group, table row selection (aria-label names the row).

Sizes

One size (20px box); the label row is at least 24px tall, 44px on coarse pointers.

States

DefaultHoverFocusDisabledInvalid
Unchecked
Checked
Indeterminate————

Indeterminate is set from script (input.indeterminate = true) on the select-all header checkbox when some rows are selected.

Responsive behaviour

  • Labels wrap beside the box; the box aligns to the first line.
  • Under (pointer: coarse) the hit area grows to --target-comfortable (44 × 44 px, L2-084); fine pointers keep the visual size, never below --target-min (24 px).

Theming

Reads --color-accent (checked fill), --color-fg-on-accent (mark), --color-border-strong.

Accessibility

Role and pattern

Native <input type="checkbox"> wrapped in its label; groups in <fieldset>/<legend>.
