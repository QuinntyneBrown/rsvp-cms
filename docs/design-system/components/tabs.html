Tabs

The event sub-navigation: Overview, Page, Guests, Emails, Responses, Settings. Implemented as links with aria-current, not ARIA tabs.

Overview

Each tab is its own route, so the component is a <nav> of links styled as an underline tab bar (the mocks’ decision). Use the tablist variant only for switching panels inside one page without changing the URL (none in the current mocks); it then follows the APG Tabs pattern with manual activation.

Anatomy

  1. BarBottom border --color-border-default; scrolls horizontally.
  2. Tab44px, --text-label, muted.
  3. Indicator2px --color-accent under the current tab.

Accessibility

Role and pattern

<nav aria-label="Event sections"> of <a> with aria-current="page". The optional panel variant uses APG Tabs (role=tablist/tab/tabpanel, arrows move, Enter/Space activate — manual activation).
