Textarea

Multi-line text: dietary needs, a message for the host, notes about a guest, block copy in the page editor.

Overview

Use when the answer can run past one line. Pair with a counter when there is a limit (message: 280). Resizes vertically only.

Anatomy

  1. ContainerMin height 2.5 × control height, vertical resize.
  2. Counter (optional)In Field, right aligned: “n of 280”.

Variants

Allergies and anything the kitchen must know.
11 of 280
Plain, with counter.

Sizes

One size; height comes from <code>rows</code> (minimum 2).
