SideNav

The organiser’s primary navigation: Dashboard, Events, Notifications (with unread count), then the Account group.

WCAG 2.2 AAStatus: stableReact: SideNav

Overview

Links with aria-current="page" on the current section. Persistent from MD; a drawer below MD (see AppShell for the decided SM behaviour). Event sub-sections are Tabs, not SideNav items.

Navigation layout (decision): XS < 576px — the menu IconButton opens the SideNav as a full-width panel over a backdrop; SM 576–767px — still collapsed behind the menu button; the panel opens as a left drawer --layout-drawer-width (320px) wide over a backdrop, page content keeps the full width with --layout-margin (16px) gutters; MD ≥ 768px — persistent SideNav (--layout-sidebar-width, 256px) beside the content, menu button hidden (L2-080).

Anatomy

  1. BrandProduct link to Dashboard.
  2. Nav linkIcon + label, 44px tall, --radius-md.
  3. Count badgeUnread notifications, with aria-label.
  4. Group labelOverline “Account”.

Responsive behaviour

  • XS: full-width drawer. SM (576–767px): 320px drawer over a backdrop (decision). MD+: persistent 256px column, sticky, scrolls independently.

Theming
