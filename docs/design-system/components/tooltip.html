Tooltip

A short text label that appears on hover and focus of an IconButton, repeating its accessible name.

WCAG 2.2 AAStatus: stableReact: Tooltip

Overview

Only for icon-only controls (topbar notifications). Never holds interactive content or information that is not also in the name.

Anatomy

  1. Bubble--color-bg-inverse, caption text, --radius-sm.
  2. Arrow5px.
  3. TriggerThe IconButton.

Variants

3 unreadClose
Above (default), below (near the top edge).

One size.

Responsive behaviour

  • Touch devices: not shown (no hover); the name is in aria-label and the icon is standard.

Theming

Inverse surface: dark in light theme, light in dark theme.

Accessibility

Role and pattern

role="tooltip", referenced by aria-describedby only when it adds to the name; when it repeats the name, it is aria-hidden. APG Tooltip.

Keyboard

KeyAction
Focus triggerShows.
EscHides without moving focus (1.4.13).

Focus

Stays on the trigger.

Labelling

Text equals or extends the trigger name.

Contrast

Live ratios for the token pairs this component relies on, in both themes. Every pair is also listed in tokens/contrast-pairs.json and checked by check_contrast.py.

Text
Text

Motion

Fades over --duration-fast after a 300ms hover delay; hides immediately.

Touch

Not used on touch.

Content

  • One to three words.
