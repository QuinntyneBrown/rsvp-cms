Spacing

Fourteen steps on a 4px grid. Small gaps hold related things together; large gaps separate what is not related.

4px base14 steps
  • Overview
  • Scale
  • Inside versus between
  • Padding by size
  • Usage

Overview

Spacing in Invitely is a 4px scale used through layout primitives. Every gap, padding and margin in components.css is one of these tokens; the harvest found the mocks' own spacing already on the grid apart from inline one-offs.

Scale

Fourteen steps on a 4px base. The token number is the multiple of 4px: --space-6 is 24px. Half a step (--space-0-5, 2px) exists for hairline gaps only.

--space-24Off-screen offset for the skip link before it is focused.

Inside versus between

The one rule: space inside a component is smaller than space between components. Components use --space-6 or less inside; layouts use --space-6 or more between blocks. Related things sit closer than unrelated things, so grouping reads without borders.

Usage

  • Space with gap, not margins: .stack, .cluster and .grid own the space between their children.
  • Never write a spacing value that is not a token. The harvest found 127 inline margin-top styles in the mocks (68 of them on the element right after a card or dialog title); the system replaces them with .stack on the card.
  • Spacing does not scale with the viewport; the breakpoint changes --layout-gutter and --layout-margin instead (see Layout).
  • Optical exceptions (an icon nudged by 2px to sit on the text baseline) use --space-0-5 and are commented in the CSS.
