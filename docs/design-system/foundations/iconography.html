Iconography

One stroke icon family on a 24-unit grid. Icons support labels, take the colour of their text and mean one thing everywhere.

Overview

Invitely uses one line-icon family, drawn on a 24-unit grid with a 2px round-capped stroke and no fill, coloured with currentColor so an icon always matches the text beside it. The 29 icons below are every distinct icon in the 166 mocks; two more were added while extracting the system. Icons support a label; they rarely replace one.

  • Inline SVG only: <svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><path d="…"/></svg>. No icon font, no sprite request.
  • One meaning per icon across the product (WCAG 3.2.4). If two actions need different icons, they are different actions.
  • Stroke, never filled, so weights match at every size.

Sizes and grid

Three sizes, set by class, never by width attributes. Inside a button the icon is 1.25em, so it scales with the button's font size.

Small for dense rows and inline status; default for buttons and nav; large for empty states and the brand mark.
ClassSizeUse
.icon--sm1rem (16px)Inline status, breadcrumbs, small chips.
.icon1.25rem (20px)Buttons, nav links, alerts, toasts, inputs.
.icon--lg1.5rem (24px)Brand mark, empty-state circles, dialog icons.
.btn .icon1.25emFollows the button's font size across sm/md/lg.

  • Lead with the icon in buttons and nav links; trail it only for direction (Export ↓, external link ↗).
  • Import uses upload (arrow out of the tray); Export uses download (arrow into the tray). The mocks used a download arrow for both.
  • Use the icon's meaning from the table above; do not borrow refresh for “Undo”, or trash for “Clear”.
  • Icons take the colour of their text. Status colour comes from the alert, toast or badge they sit in, never set on the icon by hand.
  • To add an icon: draw it on the 24-unit grid with a 2px stroke, add it to this sheet with its meaning, then use it.

Accessibility

  • Decorative icons (next to a visible label) carry aria-hidden="true" and no title.
  • Icon-only controls name the action and the object with aria-label (“Remove guest Jonah Adeyemi”, “Move hero down”) and show a tooltip on hover and focus.
  • Meaningful icons have at least 3:1 contrast with their background (WCAG 1.4.11): they inherit text colours that already pass 4.5:1, and status icons use the --color-*-icon tokens checked in contrast-pairs.json.
  • Icons never carry meaning alone: every status icon in the mocks sits next to words.
  • Hit areas come from the control, not the glyph: an icon-only button is at least 32px (small) and usually 40px.

Tokens

Icons have no tokens of their own. Colour comes from the text tokens on the color page through currentColor (status icons use --color-info-icon, --color-success-icon, --color-warning-icon, --color-danger-icon, and the …-icon-on-inverse set inside toasts). Size lives in components.css as the three classes above; the stroke width (2) and grid (24) are fixed by the SVG markup.
