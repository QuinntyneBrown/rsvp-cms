Shape

Overview

Invitely's shapes are soft but not round: 8px corners on controls, 12px on cards and dialogs, pills for status. The harvest found every radius in the mocks already on the scale except one hard-coded tab indicator.

Radius scale

Five radii and a pill. Radius grows with the size of the element, so a small control inside a large container still looks nested: 8px buttons inside 12px cards inside a 16px phone sheet.

TokenValueUsage
--radius-xsCheckboxes, the tab indicator's top corners, sort buttons, inline links' focus ring.
--radius-smTooltips, menu items, skeleton text, inline code, close buttons.
--radius-mdButtons, inputs, selects, alerts, toasts, menus, wells, pagination, nav links.
--radius-lgCards, table wrappers, dialogs from sm up, drop zones.
--radius-xlTop corners of the bottom sheet a dialog becomes on phones.
--radius-fullBadges, chips, avatars, switches, progress bars, spinners, dots.

Which radius for which size

Element sizeRadiusExamples
≤ 20px marks--radius-xsCheckbox, tab indicator
Small overlays and inline bits--radius-smTooltip, menu item, code
Controls 32–48px tall--radius-mdButton, input, select, alert, toast
Containers--radius-lgCard, table, dialog
Full-width sheets--radius-xl (top only)Dialog on phones
Pills and circles--radius-fullBadge, chip, avatar, switch

Border widths

Two widths. Hairline (1px) draws every edge; thick (2px) marks state: the selected tab, the current step, the focus ring width. Alerts use a 4px left edge (--space-1) as an accent bar, and the guest-import drop zone uses a dashed hairline.

TokenValueUsage
--border-width-hairlineEvery border: cards, inputs, dividers, table rules.
--border-width-thickSelected tab indicator, stepper circles, spinner ring, kbd bottom edge, avatar-group separation.

Usage

  • Pick the radius by the element's size, not by taste; nested elements never have a larger radius than their container.
  • Joined controls (input with addon, segmented buttons) round only their outer corners.
  • Use --radius-full for pills and circles; never 50% on a non-square element.
  • Off-scale values found in the mocks were snapped: the tab indicator's 2px 2px 0 0 is now --radius-xs; badges' 22px height is now 24px.

Accessibility

Shape never carries meaning on its own. Control edges use --color-border-strong at 3:1 (1.4.11); the focus ring follows the element's radius and is 2px wide with a 2px offset, so it reads on any corner.
