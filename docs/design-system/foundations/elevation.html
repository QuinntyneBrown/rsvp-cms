Foundation

Elevation

Four shadows, four surfaces and nine layers decide what floats over what. In dark, surfaces get lighter as they rise.

4 shadows9 layers
  • Overview

  • Surface hierarchy
  • Z-order
  • Usage
  • Accessibility

Overview

Elevation in Invitely is three things working together: shadow level, surface colour and stacking layer. Light themes lean on shadows; the dark theme leans on lighter surfaces.

Shadow levels

Four levels and a focus ring. Each level is two layered shadows (a tight contact shadow and a soft ambient one) mixed from --shadow-color, so a theme changes all of them by changing one value. Elevation says what floats over what; it never decorates.

--shadow-focusA box-shadow focus ring for elements whose outline would be clipped by overflow: hidden. The default ring is an outline; no component needs this yet.

Surface hierarchy

Four surfaces stack in a fixed order. In light, canvas is gray and every surface above it is white, so shadow and border do the lifting. In dark, shadows barely show against near-black, so each level is also lighter: canvas, then surface, then raised. Sunken sits inside a surface, a step below it, for wells, table headers and code.

surface · card, --shadow-1
sunken · well, table header
raised · dialog, menu, --shadow-4

Z-order

Nine named layers. A component never writes a raw z-index; it picks a layer. The gaps between values leave room for local stacking inside a layer (for example calc(var(--z-modal) + 1) for a dialog opened from a dialog), but stacked dialogs are avoided by design.

--z-base0 · Normal flow.
--z-raised1 · Sticky table header cells, a focused input inside an input group.
--z-sticky100 · Top bar.
--z-dropdown1000 · Menus (account menu, row-action menus).
--z-overlay1200 · Modal backdrop.
--z-modal1300 · Dialogs and sheets.
--z-popover1400 · Reserved: popovers are not part of the system yet (no mock needs one).
--z-toast1500 · Toast region: above dialogs so a save confirmation is never hidden.
--z-tooltip1600 · Tooltips and the focused skip link: always on top.

Usage

  • Raise only what floats over other content: menus, dialogs, toasts, tooltips. Cards rest at level 1 and lift to level 2 only when the whole card is a control.
  • Pair a surface with its shadow: raised surfaces take --shadow-3 or --shadow-4; never a big shadow on a resting card.
  • In dark, do not rely on shadow alone: use the raised surface colour, which is lighter.
  • Do not nest elevated surfaces more than one level: a card inside a card becomes a .well (sunken) instead.
  • Backdrops sit only behind modal dialogs; the page behind is inert.

Accessibility

  • Elevation is never the only cue: raised surfaces also differ in colour (dark) or carry a 1px border (light cards), so forced-colours and low-vision users still see edges.
  • Under forced-colors: active shadows disappear; components add a CanvasText border.
  • Layers keep focus visible (2.4.11): toasts are bottom-right and never cover the focused control; the sticky top bar is offset by scroll-padding-top.
