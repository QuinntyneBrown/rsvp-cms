# Invitely design system

Extracted from [docs/mocks](../mocks/README.md) on 2026-10-20. Open [index.html](index.html) in a browser (it works from disk; press `t` to switch theme).

The system is the RSVP CMS's visual and interaction language written down once: 214 tokens in light and dark, 12 foundation pages, 42 component pages and 8 pattern pages, at WCAG 2.2 AA. `src/shared/ui/components/` implements the component pages one folder each (see [AGENTS.md](../../AGENTS.md)).

## Tokens

- [`tokens/tokens.css`](tokens/tokens.css) — the source of truth: primitives (`--palette-*`, `--font-*`), semantic tokens (`--color-*`, `--text-*`, `--space-*`, `--radius-*`, `--shadow-*`, `--duration-*`, `--z-*`, `--layout-*`) and the dark theme. Light applies on `:root` and `[data-theme="light"]`; dark on `[data-theme="dark"]` and, unless the page forces light, `prefers-color-scheme: dark`.
- [`tokens/tokens.json`](tokens/tokens.json) — W3C DTCG export generated from `tokens.css` (`tokens_to_json.py`); aliases stay aliases, dark values sit under `$extensions`.
- [`tokens/contrast-pairs.json`](tokens/contrast-pairs.json) — the 79 foreground/background pairs the components rely on, checked in both themes by `check_contrast.py`.
- [`assets/components.css`](assets/components.css) — every component class, token-driven, with real pseudo-class states and `data-state` hooks for static review.
- [`assets/ds.css`](assets/ds.css) and [`assets/ds.js`](assets/ds.js) — the documentation site's own chrome (theme toggle, live token values and contrast ratios). Not product code.

## Drift found in the mocks

Every place the mocks disagreed with the system, and what the system does instead. The mocks have not been edited; point them at these files to pick the fixes up.

| Mock | Issue | Resolution |
|---|---|---|
| `all 8 form-summary mocks` | The danger summary alert has no icon, unlike every other alert. | Summary carries the warning icon in --alert-icon. |
| [assets/tokens.css](../mocks/assets/tokens.css) | Six dark-theme semantic tokens held raw hex values (#e9ecf1, #b3bac5, #959eab, #2f3640, #8d97a5, #14181e) instead of aliasing primitives, so the primitive tier was incomplete. | Promoted to primitives --palette-gray-125/350/425/450/775/925; the dark theme now aliases them. |
| [assets/tokens.css](../mocks/assets/tokens.css) | Muted text measured 4.48:1 (light, gray-600 #5e6675) and 4.49:1 (dark, #b3bac5) on --color-bg-subtle-hover, just under the 4.5:1 that L2-085 requires for text in both themes. | gray-600 darkened to #586070 and gray-350 lightened to #bac1cc; muted text now clears 4.5:1 on every surface it can sit on. |
| [assets/tokens.css](../mocks/assets/tokens.css) | Breakpoints were the starter's 640/768/1024/1280px, but docs/specs L2-080 to L2-083 define the viewport bands as 576/768/992/1200px; the sidebar only became persistent at 1024px where L2-080 requires 768px, and dialogs were up to 768px wide where L2-083 caps them at 560px. | --layout-breakpoint-sm/md/lg/xl are 36/48/62/75rem; sidebar persistent from 48rem; dialogs centred at most --layout-dialog-max (35rem) from 36rem and full screen below; new --layout-container-guest, --layout-form-max, --layout-dialog-max and --layout-drawer-width tokens. |
| [assets/tokens.css](../mocks/assets/tokens.css) | The dark theme wrote six raw hex values into semantic tokens (fg-default, fg-muted, fg-subtle, border-default, border-strong, bg-surface-sunken), so those values had no primitive. | Promoted to in-between gray primitives used only by the dark theme; semantic tokens now alias them (foundations/color.html#ramps). |
