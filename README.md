# rsvp-cms

A content management system for event RSVPs. Organizers create events, manage guest lists and invitations, and review responses. Guests reply through a public RSVP page.

## Setup

```
npm install
npm test
npm run typecheck
npm run lint
```

Documentation lives in `docs/` (specs, mocks, detailed designs, estimates). See `AGENTS.md` for the folder structure and rules.
